# Fix My Code Challenge

Repository for the Holberton "Fix My Code Challenge" project.

## Files

- `challenge/0-fizzbuzz.py`: Python script that prints the FizzBuzz sequence from 1 to a given number.

## Usage

Run the script with a number argument:

```bash
./challenge/0-fizzbuzz.py 15
```

Expected output for `15`:

```text
1 2 Fizz 4 Buzz Fizz 7 8 Fizz Buzz 11 Fizz 13 14 FizzBuzz
```

## Requirements

- Python 3
- Executable permissions on `challenge/0-fizzbuzz.py`
